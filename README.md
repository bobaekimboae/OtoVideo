# OtoVideo

OtoVideo는 차량 매물 정보와 사진을 입력해 세로형 숏폼 영상을 만드는 한국어 웹 앱입니다. 이미지는 브라우저에서 처리되며, 완성된 MP4를 미리 보고 내려받을 수 있습니다.

## 시작하기

```bash
npm install
npm run dev
```

## 사용 방법

1. 매물 링크를 입력하거나 매물 설명을 붙여넣고, 또는 차량 정보를 직접 입력합니다.
2. JPG, PNG 또는 WebP 차량 사진을 추가하고 순서를 정합니다. 최대 10장, 각 20MB까지 지원합니다. HEIC은 먼저 JPG로 변환하세요.
3. 화면 비율과 영상 스타일을 선택합니다. 숏폼은 9:16을 선택하세요.
4. `영상 만들기`를 누른 뒤 생성된 영상을 미리 보고 MP4를 다운로드합니다.

영상 인코딩은 사용자의 브라우저에서 실행됩니다. 사진과 차량 입력값을 서버로 전송하지 않습니다. 원본 매물 링크를 읽는 것은 사이트의 CORS 정책에 따라 실패할 수 있으므로, 이 경우 매물 설명 붙여넣기 또는 직접 입력을 이용하세요.

## 배포

GitHub Actions가 `main` 브랜치 변경 시 GitHub Pages에 빌드 결과를 배포합니다. 저장소의 Settings → Pages에서 배포 소스를 GitHub Actions로 설정하세요.

## 범위

이 앱은 사진과 입력한 정보를 이용해 브라우저에서 MP4를 합성합니다. OtoVideo 계정 로그인, 크레딧 결제, 원본 서비스의 생성 API, 이메일 발송, SNS 게시, 외부 음성 생성과 연동하지 않습니다.
